PERSONAL PROJECT · FRONTEND DEVELOPMENT

Arora Trading Company

A responsive e-commerce web application designed and developed from the ground up with a focus on interactive interfaces, responsive layouts and user experience.

React.js JavaScript HTML5 CSS3 Responsive Design

Project Overview

Arora Trading Company (ATC) is a personal e-commerce project created to practice and demonstrate frontend development, responsive design and interactive web experiences.

The project focuses on creating a structured shopping interface where users can navigate through the application and interact with different parts of the website across different screen sizes.

My Role

Frontend Developer

I designed and developed the frontend independently, working on the interface structure, responsive layouts, navigation, styling and interactive elements.

What I Built

Responsive Interface

Created layouts that adapt across different screen sizes using responsive CSS techniques.

Interactive UI

Implemented interactive elements and navigation to create a more engaging user experience.

Reusable Components

Structured the React interface into reusable components to keep the frontend organized and maintainable.

E-Commerce Experience

Designed product-focused layouts and user flows around a simple online shopping experience.

Design & Development

While building ATC, I focused on keeping the interface visually consistent and easy to navigate. I experimented with layouts, spacing, responsive behavior and interactive elements to improve the overall experience.

What I Learned

This project strengthened my understanding of component-based frontend development, responsive design and the process of turning an idea into an interactive web application.
